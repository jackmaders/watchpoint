## Reproduction commands

The preview build was produced with the preview environment and the existing local preview D1 database was migrated before starting the preview server:

```sh
CLOUDFLARE_ENV=preview vp build
vpr db:migrate --local --env preview
BETTER_AUTH_URL=http://localhost:4173 BETTER_AUTH_SECRET=template-ci-local-only-secret-value vp preview --port 4173
vp node docs/reviews/implementation-inspection.mjs
vp node docs/reviews/implementation-invalid-state-probe.mjs
```

The inspection scripts write only to `docs/reviews/evidence/implementation/`. They include screenshots at equal viewports for light/dark captures and computed measurements in the linked JSON files.

The final destructive-token remeasurement used a fresh `CLOUDFLARE_ENV=preview vp build`, a preview server with `BETTER_AUTH_URL=http://localhost:4194`, and `vp node docs/reviews/implementation-invalid-state-probe.mjs`. A previous server briefly used a mismatched auth origin and returned Better Auth `Invalid origin`; that was a local test setup error, not an application defect.
